# BAISOUND Voice Model 利用・悪用防止ガイドライン

最終更新日：2026-09-22

## 1. 適用範囲

このガイドラインは、BAISOUND Voice Modelのモデル重み、同モデルで生成した音声、および関連する配布物の利用に適用します。リポジトリへアクセスできることは、利用許諾を意味しません。モデルを利用できるのは、BAISOUNDから別途明示的な許可を受けた方に限られます。

許諾を受けた利用者も、[MODEL_LICENSE.md](../MODEL_LICENSE.md)、本ガイドライン、第三者ライセンス、適用法令、利用先プラットフォームの規約を守る必要があります。

## 2. YouTube概要欄への必須表記

本モデルまたは本モデルで生成した音声をYouTube動画で使用する場合、**対象となるすべての動画の概要欄**へ、次の2行を省略せず、視聴者が確認できる状態で記載してください。

```text
AI音声: BAISOUND Voice Model v2.0.0
配布元: https://github.com/baisound/BAISOUND_VOICE_MODEL
```

- クレジットを折りたたみの奥へ意図的に隠す、読めない表記にする、削除する、または別製品の表示に置き換えることは禁止します。
- Shorts、ライブ配信のアーカイブ、切り抜き、再投稿にも同じ条件が適用されます。
- YouTube以外で公開する場合も、説明欄やクレジット欄など、利用者が容易に確認できる場所へ同等の表示を行ってください。
- 合成音声を本人の実発言と誤認させる表示は禁止します。

## 3. 禁止する悪用

次の行為を禁止します。

1. 本人が実際に発言・推奨・承認したと誤認させるなりすまし、偽装、ディープフェイク
2. 詐欺、フィッシング、金銭要求、本人確認の突破、社会的信用を利用する行為
3. 名誉毀損、侮辱、脅迫、嫌がらせ、差別、扇動、または第三者へ実害を与える行為
4. 違法行為、犯罪行為、規制逃れを助長する目的での利用
5. 性的搾取、児童を害する内容、同意のない性的表現への利用
6. 虚偽の広告、政治的・宗教的支持、投資・医療・法律上の助言などを本人の見解として捏造する行為
7. 第三者の著作権、商標権、プライバシー、肖像、名誉、その他の権利を侵害する行為
8. モデル重み、参照音声、非公開資料の無断複製、再配布、販売、サブライセンス、抽出、解析
9. 必須クレジット、出所表示、利用制限、技術的保護を削除・回避・改変する行為
10. 違反行為を第三者へ依頼、仲介、支援し、または違反物の拡散を継続する行為

風刺、創作、検証などの名目であっても、本人の実発言と誤認させる利用や、他者へ実害を与える利用は認められません。

## 4. 違反時の対応

BAISOUNDは、違反または悪用を確認した場合、証拠を保全したうえで、事案に応じて次の対応を行います。

- 利用許諾の停止または取消し
- コンテンツ削除、公開停止、モデル・生成物の回収要求
- YouTubeその他のプラットフォーム、ホスティング事業者、決済事業者等への通報
- 差止め、発信者情報開示請求、損害賠償請求、弁護士費用その他の民事上の請求
- 犯罪に該当する合理的な疑いと証拠がある場合、警察・検察等への相談、被害申告および**刑事告訴**

権利侵害または規約違反により損害が発生した場合、BAISOUNDは適用法令および証拠に基づき、当該損害の賠償を請求します。告訴後の捜査、起訴、処分、裁判の判断は、捜査機関・検察官・裁判所が法令に基づいて行います。

日本法上、故意または過失による権利・法律上保護される利益の侵害には不法行為に基づく損害賠償責任が生じ得ます。また、犯罪による被害者には告訴をする権利が定められています。個別事案では、証拠、適用法、管轄、当事者関係を確認したうえで専門家と対応します。
