
# BAISOUND Fine-Tuned Model Weights — Licensing Status

## Current status

The BAISOUND-specific fine-tuned GPT-SoVITS checkpoints in this repository have **no
automatic public redistribution grant** in this initial repository configuration.

They are intended for private/internal BAISOUND project use until an explicit model
distribution license is selected.

## Third-party basis

The fine-tuned checkpoints were produced using GPT-SoVITS v2Pro components.
GPT-SoVITS source code is published by RVC-Boss under the MIT License, and the
`lj1995/GPT-SoVITS` Hugging Face pretrained-model repository is currently marked MIT.

Those upstream licenses do not replace the need to make an explicit decision about:

- distribution of BAISOUND-specific fine-tuned weights;
- rights in the voice/persona represented by the model;
- dataset/privacy obligations;
- downstream use restrictions, if any.

## Before making this repository public

Confirm and record:

1. the exact upstream pretrained checkpoints used;
2. their license/revision at training time;
3. the selected BAISOUND model-weight license;
4. whether public redistribution is authorized;
5. whether generated-voice use requires additional policy terms.

Until then, treat the weights as private artifacts.

This file is a project policy notice, not legal advice.
